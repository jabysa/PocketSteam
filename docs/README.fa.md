# PocketSteam

**زبان:** [English](../README.md) · فارسی · [العربية](README.ar.md)

اجرای Steam روی ویندوز از داخل یک پوشه، بدون اجرای نصاب Steam.
فقط از کتابخانه استاندارد پایتون استفاده می‌کند؛ نیازی به pip، Wine یا CrossOver ندارد.

## شروع سریع

۱. **Python 3.9 یا جدیدتر** را از [python.org](https://www.python.org/downloads/windows/) نصب کن. اگر گزینه **Add Python to PATH** نمایش داده شد، فعالش کن.
۲. از صفحه مخزن **Code → Download ZIP** را بزن و فایل را در پوشه‌ای قابل نوشتن، مثلاً دسکتاپ، استخراج کن.
۳. اگر Steam باز است، با **Steam → Exit** کامل ببندش.
۴. روی **`Start Steam.cmd`** دوبار کلیک کن.
۵. منتظر دانلود فایل‌ها بمان، سپس داخل خود Steam وارد حسابت شو.

دفعات بعد هم همان **`Start Steam.cmd`** را اجرا کن. فایل‌های پروژه را کنار هم نگه دار.
ویندوز ۶۴ بیتی پشتیبانی‌شده توسط Steam، اینترنت و فضای کافی برای کلاینت و بازی‌ها لازم است.

اجرای دستی در ترمینالِ پوشه پروژه:

```powershell
python steam_portable.py
```

اگر `python` شناخته نشد، `py -3 steam_portable.py` را امتحان کن.

## روش کار

لانچر بسته راه‌انداز را مستقیم از Valve دریافت می‌کند، اندازه و SHA-256 را با فهرست رسمی تطبیق می‌دهد و فقط `Steam.exe` را داخل `Steam/` می‌نویسد.
قبل از اجرا در ویندوز، امضای معتبر Valve را با Authenticode بررسی می‌کند. سپس خود Steam بقیه فایل‌ها را دانلود و به‌روزرسانی می‌کند.
اگر Steam.exe موجود باشد، دوباره دانلود نمی‌شود ولی امضای آن پیش از اجرا بررسی می‌شود.

## محدودیت‌ها

این لانچر `SteamSetup.exe` را اجرا نمی‌کند؛ اما Steam را از ویندوز جدا و ایزوله نمی‌کند:

- خود Steam ممکن است در AppData و Registry بنویسد یا برای سرویس Steam و پیش‌نیازهای بازی مجوز مدیر بخواهد. لانچر این درخواست‌ها را خودکار تأیید نمی‌کند.
- اجرای آنلاین و VAC بدون سرویس‌های لازم تضمین نشده است.
- قبل از جابه‌جایی پوشه، Steam را کامل ببند. حذف پوشه `Steam/` بازی‌ها و داده‌های داخلش را هم حذف می‌کند و لزوماً داده‌های بیرون آن را پاک نمی‌کند.

## فایل‌ها

- `steam_portable.py`: دانلود و اجرا
- `Start Steam.cmd`: اجرای آسان روی ویندوز
- `test_launcher.py`: تست خواندن فهرست دانلود
- `Steam/`: فایل‌های دانلودی و داده‌های محلی؛ در Git ثبت نمی‌شود

## رفع مشکل

- **Python پیدا نمی‌شود:** پس از نصب، ترمینال را دوباره باز کن و `python --version` یا `py -3 --version` را بررسی کن.
- **خطای امضا یا SHA-256:** فایل را دستی اجرا نکن؛ اتصال و نسخه جدید لانچر را بررسی کن.
- **خطای ساختار فهرست:** ممکن است فرمت Valve تغییر کرده باشد و لانچر نیاز به به‌روزرسانی داشته باشد.
- گزارش‌ها در `Steam/logs` هستند؛ قبل از اشتراک‌گذاری، اطلاعات حساب را بررسی کن.

## تست و بررسی

```powershell
python -m unittest -v
```

آماده‌سازی بدون اجرا، روی مک هم قابل استفاده است:

```sh
python3 steam_portable.py --prepare-only
```

این گزینه بسته دانلودی را بررسی می‌کند؛ بررسی امضای Authenticode فقط هنگام اجرای معمول روی ویندوز است.
تست‌های خواندن فهرست و دانلود واقعی با بررسی اندازه و SHA-256 روی مک موفق بوده‌اند؛ اجرای نهایی و بررسی امضا روی ویندوز هنوز تست نشده‌اند.
